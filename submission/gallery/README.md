# Gallery

Fourteen 3:2 screenshots (1800x1200) of the running application for the Devpost image gallery, captured by `scripts/dev/gallery.ts` and captioned by `scripts/dev/gallery-captions.py`. Raw captures are in `raw/`. The verification runs, policy decisions, and audit rows shown are real records produced by the verification engine on a hand-written test deliverable (see `scripts/dev/seed-demo-run.ts`); no PayPal credentials were present, which is why captures read zero.
